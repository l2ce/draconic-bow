# Draconic Bow

Браузерная 3D-сцена Lineage II High Five: **Human Female Fighter**, **Plated Leather Set**, **Draconic Bow**. React, TypeScript, Vite и Three.js. Одна фиксированная экипировка, без инвентаря и игрового сервера.

- Вращение, приближение и сброс камеры; стойка, ходьба и бег на месте.
- Тёмная графитовая тема, пауза, автоповорот, сетка и каркас.
- Заточка +0…+16: попытка длится 3 секунды, показывает прогресс и блокирует повторное нажатие.
- Успех даёт +1, неудача — +0 без уничтожения лука. До +3 шанс 100%, затем линейно снижается до 10% на попытке +15→+16. Это условная шкала, не данные игрового сервера.
- Аура появляется с +4, частицы — с +7, красное свечение — на +16. После перезагрузки уровень снова +0.

## Локальный запуск

Нужны Node.js 24 LTS и npm. Готовые ресурсы уже лежат в `public/`; Blender и полный клиент для запуска не нужны.

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5183. `npm ci` выполнять до запуска сервера. Dev-сервером управляет пользователь; агент не перезапускает его и не очищает кеш.

## GitHub Pages

Адрес после публикации: **https://l2ce.github.io/draconic-bow/**.

1. В репозитории GitHub открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. Разрешить запуск GitHub Actions и, если потребуется, подтвердить окружение `github-pages`.
3. Отправить ветку `main`. Workflow [pages.yml](./.github/workflows/pages.yml) установит зависимости по lockfile, соберёт сайт и опубликует только `dist/`. Повторная публикация — при пуше в `main` или вручную через Actions.

Для первого коммита и пуша:

```bash
git add .
git commit -m "Initial commit"
git push -u origin main
```

Workflow получает базовый путь сайта из GitHub Pages. Загрузка модели, эффектов, текстур и ссылки учитывают этот путь; локально приложение остаётся на `/`. Секреты и отдельная ветка `gh-pages` не нужны. Для самостоятельной сборки под текущий адрес:

```bash
npm run build -- --base=/draconic-bow/
```

## Разработка и ресурсы

- [docs/development.md](./docs/development.md) — устройство кода, важные настройки рендера и dev-диагностика.
- [docs/assets.md](./docs/assets.md) — происхождение модели/эффектов и инструменты подготовки.
- [tools/README.md](./tools/README.md) — воспроизводимые скрипты извлечения и сборки ресурсов.

Полный клиент, рабочие `.blend`, выгрузки и отчёты остаются вне репозитория в соседних `client-high-five/` и `asset-work/`. `node_modules/`, `dist/`, кеши и локальная конфигурация исключены из Git.

Тестирование и визуальную приёмку выполняет пользователь. Агент не запускает проверки, сборку и браузерные сценарии без отдельного запроса; тестовая инфраструктура не добавляется.

**Игровые модели и текстуры принадлежат правообладателям. Наличие клиента не означает разрешение на их публичное распространение — это следует учитывать перед публикацией.** Лицензии сторонних XML-схем сохранены в `tools/schemas/`.
